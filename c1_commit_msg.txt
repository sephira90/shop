refactor(catalog): relocate Catalog read slice to app/Domains/Catalog (C1)

First runtime module move of the convergence waves: physically relocates the
public Catalog read slice into app/Domains/Catalog with namespace moves and
zero dual-namespace shims. Proves the C0 module-boundary contract is
load-bearing on real code.

Contract surface (app/Domains/Catalog/Contracts/):
- CatalogProductReadRepository: paginated catalog reads (moved verbatim;
  keeps Product at boundary as documented shared-kernel allowance pending
  the post-C7 model-ownership wave).
- CatalogCacheVersion: new contract (current()/bump()) consumed by 3 admin
  services for cache invalidation, so admin writes no longer import the
  concrete CatalogVersionService.
- CatalogReadService: new contract mirroring CatalogService public surface,
  consumed by module query handlers and by the 2 performance-smoke
  scenarios measuring service-level query budgets.
- Dto/CatalogProductListFilterDto: typed filter DTO consumed cross-module
  by PerformanceSmokeSetupFactory and PerformanceSmokeContextDto.

Implementation under app/Domains/Catalog/ (all via git mv for history):
- Services/{CatalogService,CatalogVersionService}.php (now implement the
  new contracts).
- Repositories/CatalogProductReadRepository.php.
- Application/Queries/* (3 handlers + 2 payloads) and Application/Dto/*
  (7 module-internal DTOs).
- Controllers/{CatalogController,CatalogIndexRequest}.php (controller now
  final per AGENTS.md default).
- CatalogServiceProvider.php (new) binds the 3 contracts; registered in
  bootstrap/providers.php immediately after ApplicationBindingsServiceProvider.

Atomic wiring updates:
- routes/api.php import switched to App\Domains\Catalog\Controllers\CatalogController.
- ApplicationBindingsServiceProvider catalog binding + imports removed (moved
  to CatalogServiceProvider).
- AdminCatalogService/AdminCategoryService/AdminCacheService: constructor
  type CatalogVersionService -> CatalogCacheVersion.
- CatalogListCold/WarmPerformanceSmokeScenario: constructor type
  CatalogService -> CatalogReadService.
- PerformanceSmokeSetupFactory + PerformanceSmokeContextDto: FilterDto
  import -> new contract namespace.
- psalm.xml: TooManyTemplateParams per-file suppression relocated;
  app/Domains/Catalog/Repositories added to TooManyTemplateParams +
  InvalidDocblock suppressions (same Closure(Relation<*, *, *>) shapes as
  legacy app/Repositories); Contracts interfaces + Application/Dto added
  to TooManyTemplateParams.
